# Nutri-flow 实验设计与结果归档总报告

版本：v1.0

## 1. 文档目的

本文档用于把当前已经验证完成的模型实验，从分散的开发与优化记录中抽取为稳定结论，服务于三类场景：

1. 作为毕业论文实验章节的内部事实底稿。
2. 作为当前默认发布模型的选择依据。
3. 作为后续继续做模型迭代时的对照基线。

## 2. 适用范围

当前归档范围覆盖以下阶段：

1. Stage3 最终结果。
2. Stage6S6 产品可用基线。
3. Stage7S1、Stage7S2、Stage7S3 最终 gate 结果。
4. Stage8S1 最终 gate 结果。
5. 应用端默认模型切换结论。

## 3. 实验治理原则

当前项目的实验收口遵循以下原则：

1. 最终比较以 full-val 结果为准，不以训练内 proxy validation 直接替代终版结论。
2. 主指标使用 `val_mIoU`。
3. 稳定性辅助指标使用 `nonzero_non_bg_classes`，即非背景有效类覆盖数量。
4. 多阶段实验采用 gate 机制收口，当前已验证的门限为 `epsilon = 0.0005`。
5. 只有同时满足“指标更优、覆盖不显著退化、部署成本不增加或可接受”时，才允许进入默认发布候选。

## 4. 当前已确认的训练主线事实

### 4.1 数据与主干事实

1. 数据集主线为 FoodSeg103。
2. Stage3 归档显示可确认的数据规模为训练集 `4983` 张、验证集 `2135` 张。
3. 当前架构主线为 `Swin Transformer + BiFPN + Coordinate Attention`。
4. 224 分辨率用于早期基线验证，512 分辨率已成为后续产品化主线。

### 4.2 训练与评估事实

1. Stage3 归档已确认训练框架采用 `AdamW + Cosine Annealing` 学习率策略。
2. Stage7 与 Stage8 的终版实验均采用“分阶段训练 + full-val gate”机制。
3. Stage8S1 终版实验已明确固定 `batch_size=1`、`img_size=512`、`mask_head_mode=binary`。
4. Stage7S1 终版实验已明确验证出 mild mask bias 的正向价值。

说明：更细的初始化、数据增强、DataLoader 细节和脚本参数，论文定稿时应继续从训练脚本与各 stage 实验目录补录，不应凭记忆补写。

## 5. 关键结果总表

| 阶段 | 代表配置 | 阶段安排 | full-val mIoU | 非背景有效类 | 工程结论 |
|---|---|---|---:|---:|---|
| Stage3 Tiny | 224 基线 | 10 epoch | 0.0933 | 104 类日志已记录 | 建立 Transformer 主线可行性 |
| Stage6S6 PhaseC | 512 主线基线 | 20 epoch | 0.3169905754109746 | 98 | 成为产品可用基线 |
| Stage7S1 PhaseA | `mask=1.35 / cls=0.95` | 12 epoch | 0.3199287227568812 | 98 | 当前最优主线 winner |
| Stage7S2 PhaseB | `semantic head + boundary loss` | A:10 + B:8 | 0.31064224543370683 | 96 | 结构增强未跑赢主线 |
| Stage7S3 PhaseA | `binary head + boundary loss` | A:10 + B:8 | 0.3115215702123807 | 96 | 比 S7S2 更稳，但仍低于 S7S1 |
| Stage8S1 PhaseB | `weighted sampler` | A:40 + B:30 + C:20 | 0.317085687005668 | 97 | 有收益，但不足以替换 S7S1 |

## 6. 分阶段结论

### 6.1 Stage3 到 Stage6S6

1. Stage3 Tiny 证明了以 Swin Transformer 为主干的实例分割路线可行。
2. Stage6S6 PhaseC 把 full-val mIoU 提升到 `0.3169905754109746`，并将非背景有效类提升到 `98`，成为应用端的稳定产品基线。

### 6.2 Stage7S1

1. Phase A 结果为 `0.3199287227568812 / 98`。
2. 相比 Stage6S6 PhaseC，绝对提升 `+0.0029381473459066387`。
3. 提升过程中没有引入新的部署负担，也没有带来覆盖退化。
4. 结论是：温和提高 mask 分支权重有效，但激进 mask 偏置会带来回退。

### 6.3 Stage7S2 与 Stage7S3

1. Stage7S2 winner 为 `0.31064224543370683 / 96`，说明 `semantic head + boundary loss` 在当前主线上没有形成正收益。
2. Stage7S3 winner 为 `0.3115215702123807 / 96`，说明只保留低权重 boundary loss 后，路线更稳，但仍未回到 Stage7S1 水平。
3. 这两轮实验的价值主要是收窄优化边界，而不是产生新的默认主线。

### 6.4 Stage8S1

1. Stage8S1 winner 为 `0.317085687005668 / 97`。
2. 相比 Stage7S2 与 Stage7S3 明显更优。
3. 相比 Stage6S6 仅有轻微提升，相比 Stage7S1 仍低 `0.0028430357512132`。
4. 结论是：weighted sampler 值得保留为正向支线，但证据不足以替换默认主线。

## 7. 当前默认发布模型结论

当前默认发布模型应保持为 Stage7S1 PhaseA winner，对应事实如下：

1. full-val `0.3199287227568812` 为当前已验证最高值。
2. 非背景有效类覆盖保持 `98`，无回退。
3. 输入尺寸仍为 `512`，backbone 仍为 `swin_tiny_patch4_window7_224`。
4. 当前应用端与本地联调链路已验证该模型可以稳定跑通真实推理。

## 8. 对论文撰写的直接可用结论

论文中可直接使用的实验结论包括：

1. 主线性能提升主要来自对既有 Transformer 分割框架的温和调参与工程化验证，而不是频繁更换主干结构。
2. Stage7S1 证明 mild mask bias 有效，并给出当前主线可接受的权重区间。
3. Stage7S2 与 Stage7S3 提供了明确的负结论，说明不是所有结构增强都会提升 full-val 表现。
4. Stage8S1 说明长尾重采样方向有研究价值，但现阶段不足以替换默认模型。
5. full-val gate 比训练内局部验证更能代表真实主线结论，是当前实验治理的重要工程机制。
