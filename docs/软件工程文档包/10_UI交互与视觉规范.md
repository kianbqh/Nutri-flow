# Nutri-flow UI交互与视觉规范（简洁易用，暖色主题）

版本：v1.0  
目标：在 MVP 阶段提供清晰、低学习成本、可解释的移动端体验。

## 1. 设计原则

1. 简洁优先：减少认知负担，关键操作一步可达。
2. 信息分层：先总览，再明细，再解释。
3. 状态明确：处理中、成功、失败、超时一眼可辨。
4. 可解释性：结果与实例明细可追溯。

## 2. 主题方向（暖色调）

### 2.1 主色与语义色

- 主色（Primary）：#E97A3A（暖橙）
- 主色深阶：#CC642D
- 主色浅阶：#F6C3A3
- 背景色：#FFF8F3（暖白）
- 卡片底色：#FFFFFF
- 文字主色：#2E2A27
- 次级文字：#6B625D
- 成功色：#2E9B5F
- 警告色：#E2A93B
- 错误色：#D9534F

### 2.2 使用规则

1. 主要按钮使用主色实底。
2. 次要按钮使用描边样式（主色边框）。
3. 错误提示只使用错误色，不与主色混用。
4. 页面背景保持暖白，减少纯白刺眼感。

## 3. 字体与排版

1. 标题：18-22sp，Semibold。
2. 正文：14-16sp，Regular。
3. 注释：12-13sp，Regular。
4. 行高建议 1.4-1.6，保证阅读舒适。

## 4. 页面信息架构

### 4.1 首页（Capture）

1. 顶部：今日目标摘要。
2. 中部：拍照/上传入口（主按钮）。
3. 底部：最近一次分析快捷入口。

### 4.2 处理中页（Processing）

1. 显示任务状态与加载动画。
2. 提示预计等待文案。
3. 提供“返回首页”与“继续等待”。

### 4.3 结果页（Result）

1. 第一屏：总热量 + 估算提示。
2. 第二屏：分割图与实例列表联动。
3. 第三屏：详情卡片（热量、营养、简介、建议）。

### 4.4 画像页（Profile）

1. 目标类型。
2. 每日热量目标。
3. 饮食禁忌。
4. 保存反馈（toast + 状态条）。

### 4.5 历史页（History）

1. 时间倒序列表。
2. 每项显示 mealType、状态、总热量摘要。
3. 支持分页加载更多。

## 5. 交互规范

1. 点击实例时，图层高亮 + 列表同步选中。
2. 状态切换时禁止闪烁跳变，使用 150-250ms 过渡。
3. 错误场景始终提供重试入口。
4. 关键动作给出即时反馈（上传中、保存中、已完成）。

## 6. 文案规范

1. 热量文案统一使用“约 xx kcal”。
2. 必须出现“结果为估算值，仅供饮食管理参考”。
3. Agent 提示以建议语气，不使用医学结论语气。

## 7. 组件规范（MVP）

1. PrimaryButton
2. StatusBanner（PENDING/FAILED/TIMEOUT）
3. FoodItemCard
4. SegmentationCanvas
5. AdviceCard

## 8. 可用性检查清单

1. 单手操作主要路径可完成。
2. 主按钮位置一致。
3. 关键信息在 3 秒内可理解。
4. 异常场景无死路。
