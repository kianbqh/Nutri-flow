# Nutri-flow 信息架构与页面流程

版本：v1.0

## 1. 信息架构（IA）

### 1.1 顶层导航

1. 首页（拍照/上传）
2. 结果（从任务完成后进入）
3. 历史
4. 我的（目标与设置）

### 1.2 数据对象

1. UserProfile
2. AnalysisTask
3. AnalysisResult
4. DetectedItem
5. HistoryItem

## 2. 核心流程

### 2.1 首次使用流程

1. 进入应用
2. 选择“手动输入目标”或“Agent 问答”
3. 保存用户画像
4. 回到首页开始拍照

### 2.2 餐食分析流程

1. 首页选择拍照/相册
2. 选择 mealType
3. 上传并创建任务
4. 进入处理中页轮询状态
5. 完成后进入结果页
6. 查看总热量与实例详情
7. 自动写入历史记录

### 2.3 历史回看流程

1. 进入历史页
2. 分页加载记录
3. 点击某条记录进入详情

## 3. 页面级功能清单

### 3.1 CapturePage

1. 图片选择入口
2. mealType 选择
3. 上传按钮
4. 上传失败提示

### 3.2 ProcessingPage

1. 状态展示
2. 超时提示
3. 重试/返回操作

### 3.3 ResultPage

1. 总热量卡片
2. 分割图层
3. 实例列表
4. 实例详情抽屉/弹层
5. 建议卡片

### 3.4 ProfilePage

1. 健康目标
2. 每日热量目标
3. 饮食禁忌
4. 保存反馈

### 3.5 HistoryPage

1. 记录列表
2. 分页加载
3. 状态标签

## 4. 交互流转图（文本版）

1. AppStart -> Onboarding -> Capture
2. Capture -> Upload -> Processing
3. Processing -> Completed -> Result
4. Processing -> Failed -> RetryUpload
5. Processing -> Timeout -> RetryPolling
6. Result -> SaveHistory -> History

## 5. 关键可用性约束

1. 任意失败都有下一步动作。
2. 任意状态都有可理解提示。
3. 任意结果都可追溯到实例明细。
