# Model Release Baseline

Version: v1.1

This document defines the default segmentation model used by the application
runtime and the rule for changing it.

## Current Default

```text
Stage7S1 Phase A
nutri-ai-mcp/weights_by_category/foodseg103/stage7s1/stage7s1_tiny_img512_mask135_cls095_phaseA_12ep/best_stage7s1_tiny_img512_mask135_cls095_phaseA_12ep.pth
```

The local development script `scripts/dev-up.ps1` sets this path through
`NUTRI_SEG_CHECKPOINT`. The agent fallback configuration also points to the
same checkpoint.

Stage7S1 Phase A is kept as the release baseline because it improves mIoU over
Stage6S6 without reducing class coverage or changing the deployed inference
interface.

## Runtime Verification

Start the stack:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/dev-up.ps1
```

Then call the inference service:

```text
http://127.0.0.1:18001/v1/segment
```

The response `model_version` should include:

```text
best_stage7s1_tiny_img512_mask135_cls095_phaseA_12ep.pth
```

## Switching Rule

A new model can replace the default only if it satisfies all of the following:

1. full-val mIoU is not lower than the current default, unless there is a
   documented product reason.
2. Non-background class coverage does not regress materially.
3. Runtime smoke testing confirms the expected `model_version`.
4. Deployment cost and inference interface compatibility remain acceptable.

## Rollback

Rollback means pointing `NUTRI_SEG_CHECKPOINT` back to the previous stable
checkpoint, restarting the stack, and verifying `model_version` again through
`/v1/segment`.
