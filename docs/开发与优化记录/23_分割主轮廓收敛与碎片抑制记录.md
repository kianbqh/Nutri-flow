# 23 分割主轮廓收敛与碎片抑制记录

## 1. 文档目的

本记录用于沉淀结果页分割可视化的又一轮前端优化，目标是解决“区域太细、碎片太多、观感依旧凌乱”的问题。

## 2. 问题背景

在前一轮已经完成轻量轮廓化、底图切回原图和旧前端运行态排查后，用户仍反馈某些图片的分割结果“细碎感过强”，主要体现在：

1. 画布里同时出现过多类别轮廓。
2. 某些类别内部还有很多很小的离散边界片段。
3. 即使已经看清原图，分割轮廓本身仍然让整体画面显得复杂。

## 3. 根因定位

本轮定位到两个前端层面的直接原因：

### 3.1 画布展示范围过宽

页面下方的类别摘要已经默认只展示热量最高的前 5 类，但交互画布仍然把 `allGroups` 全量传入 `_InteractiveSegmentationCanvas`。这意味着：

1. 文本摘要是精简视图。
2. 轮廓画布却是全量视图。

两者粒度不一致，会把所有细碎类别都叠到图上。

### 3.2 同一类别内的小碎片没有被抑制

当前 `_mergeGroupMask` 会把同一类别的所有实例 mask 直接并集，但不会在展示层过滤很小的离散连通域。结果是：

1. 一些极小噪声片段也会被画出来。
2. 这些碎片会进一步放大“过细、过密”的视觉感受。

## 4. 实现方案

### 4.1 画布只展示主类别

将交互画布的输入从 `allGroups` 改为主类别集合，默认仅绘制热量最高的前 5 类轮廓。其余类别仍然保留在下方摘要和详情中，不会丢失信息。

### 4.2 展示层连通域碎片抑制

在 `_mergeGroupMask` 之后增加 UI 专用的 mask 压缩步骤：

1. 对每个类别的并集 mask 做 8 邻域连通域分析。
2. 计算最大连通域面积。
3. 仅保留面积达到阈值的连通域。
4. 阈值采用“最大连通域比例 + 上下界”方式，避免过度删除真实小块食物。

该策略只影响前端展示，不改后端推理结果和原始 mask 数据。

## 6. 预期结果

优化后应呈现以下变化：

1. 画布只保留主要类别轮廓，类别数量明显减少。
2. 同一类别内的小碎片边界被弱化或隐藏。
3. 用户仍可从下方摘要中查看完整类别信息，不影响信息完整性。

## 8. 工程结论

这次优化表明，分割结果在前端的可读性不只取决于模型本身，还取决于“展示层是否把所有细节原样端上来”。对交互画布而言，适度做主信息优先和碎片抑制，往往比继续堆叠更多轮廓更符合用户感知。
