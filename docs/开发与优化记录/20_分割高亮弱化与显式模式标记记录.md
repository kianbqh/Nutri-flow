# 20 分割高亮弱化与显式模式标记记录

## 1. 文档目的

本记录用于沉淀这样一个后续修正动作：在已经怀疑存在旧前端运行实例的情况下，继续把分割可视化的默认高亮做得更轻，并加入一个足够明显的页面模式标记，以便快速判断浏览器当前看到的到底是不是最新 UI。

## 2. 问题背景

即使完成了“取消默认选中”和“底图切回原图”的代码调整，用户最新截图仍然显示出明显的大面积橙色块，视觉观感与预期不符。

从工程角度，这里有两个可能性：

1. 当前页面仍然命中了旧 Flutter 调试包。
2. 即便已是新包，当前选中态的轮廓与徽标仍然不够轻，导致感知上差异不足。

## 3. 调整目标

本次调整不再做小幅参数微调，而是改成更容易肉眼识别的方案：

1. 直接取消选中区域的整块实心填充。
2. 仅保留柔和发光和白色主轮廓。
3. 将编号徽标统一改为浅色底 + 彩色描边。
4. 在分割区域标题下加入显式模式标记，例如“轻量轮廓模式”。

这样如果刷新后页面仍然出现整块橙色和实心编号，就能更明确地说明用户当前仍在看旧包。

## 4. 实现方式

### 4.1 去掉选中区域实心填充

在 painter 中移除了 `_paintMask(...)` 的调用，不再对选中区域进行整块半透明着色，而是仅对边界做柔和 glow。

### 4.2 弱化选中态边界

保留白色主轮廓和浅色强调线，但继续降低 glow 强度与彩色线条饱和度，使分割边界更偏“轮廓提示”而不是“涂色覆盖”。

### 4.3 统一徽标风格

无论选中还是未选中，编号徽标都改为浅色底，不再使用实心彩色底块；差异主要通过边框强度和文字颜色表现。

### 4.4 添加显式模式标记

在“可点击分割区域”标题下新增两个小型 Chip：

1. 轻量轮廓模式
2. 点击查看详情

这个改动有两个目的：

1. 强化当前交互模式的说明。
2. 为运行态核查提供一个肉眼可见的新 UI 标记。

## 5. 涉及文件

1. nutri-mobile/lib/pages/result_page.dart
2. docs/开发与优化记录/20_分割高亮弱化与显式模式标记记录.md

## 6. 预期结果

修正后，最新分割区域应当呈现如下效果：

1. 不再出现整块橙色实心填充。
2. 编号徽标改为浅底轻量风格。
3. 标题下方可以看到“轻量轮廓模式”的 Chip。

如果刷新后仍然完全看不到这些变化，则高概率说明用户当前访问的仍不是最新 Flutter 包。

## 7. 工程结论

面对“用户感知不到差异”的 UI 迭代，仅靠继续解释代码逻辑往往不够。更有效的方式是：

1. 做出足够明显的视觉差异。
2. 同时加入一个可验证的新界面标记。
3. 用运行态验证把“代码问题”和“旧包问题”彻底分开。
