# Development and Optimization Logs

This directory stores chronological engineering notes, debugging records,
experiment decisions, and UI iteration summaries.

These files are intentionally verbose. They are useful as evidence for a
graduation project or thesis, but they are not the fastest way to understand
the application. For a concise overview, start with:

- Root `README.md`
- `docs/README.md`
- `docs/软件工程文档包/README.md`
- `docs/软件工程文档包/18_模型版本基线与默认发布说明.md`
- `docs/软件工程文档包/14_Agent工作流设计.md`

## Log Scope

- Performance and stability fixes
- Segmentation visualization improvements
- Stage6/Stage7/Stage8 model experiments
- Web and Flutter UX iterations
- Agent personalization and result-page refinements

## Maintenance Rule

Keep new long-form process notes in this directory. Promote only stable
decisions, final baselines, and reviewer-facing summaries into the software
engineering document pack.
