# Nutri-flow 开发与优化记录

本目录用于集中存放开发过程中的优化记录、问题定位记录、代码修改记录和阶段性验证结论。

这类文档具有两个特点：

1. 更新频率高，会随着联调和迭代持续增加。
2. 更偏过程追踪与工程复盘，不适合混入稳定的软件工程文档包中。

## 使用约定

1. 后续每次较大的性能优化、交互修正、问题排查和代码结构调整，都优先记录到本目录。
2. 已冻结的需求、架构、接口、测试矩阵等稳定文档，继续保留在 [../软件工程文档包/README.md](../软件工程文档包/README.md)。
3. 若某次记录最终沉淀为长期约束，再考虑抽取到软件工程文档包中。

## 建议命名方式

1. 保持连续编号，便于论文和周报引用。
2. 标题尽量体现“问题 + 处理动作 + 结果”，例如“链路性能优化记录”“分割交互底图修正记录”。
