# Nuri-flow
灵动食迹 (Nutri-Flow)：基于 Swin Transformer 改进算法与 LangGraph 智能体工作流的智慧饮食管家。集成微服务架构、MCP 协议与 RAG 知识库，实现从食物分割到个性化膳食建议的闭环。   Nutri-Flow: An AI-driven dietary advisor powered by Swin Transformer (Instance Segmentation) and LangGraph (Agentic Workflow). Features microservices, MCP protocol, and RAG for personalized nutrition insights.
